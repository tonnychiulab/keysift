## 專案實作

### 核心能力

1. 比對 baseline 與 candidate `.env` 檔案。
2. 將差異分成：
   - `changed`
   - `missing_from_baseline`
   - `missing_from_candidate`
3. 只輸出鍵名與狀態，不輸出密碼、Token 或其他值。
4. 支援人類可讀 Text 與穩定 JSON 格式。
5. 支援可重複的大小寫敏感 `*`／`?` glob 忽略規則。
6. 使用固定排序，讓本機、CI 與 code review 結果一致。
7. 使用退出碼：
   - `0`：相同，或成功顯示 help／version
   - `1`：偵測到設定漂移
   - `2`：命令列、檔案存取或 `.env` 語法錯誤

### `.env` 解析決策

- 接受空白行、註解、`KEY=VALUE` 與 `export KEY=VALUE`。
- 鍵名限制為 `[A-Za-z_][A-Za-z0-9_]*`。
- 支援未加引號、單引號與雙引號值。
- 雙引號支援 `\n`、`\r`、`\t`、`\"`、`\\`。
- 重複鍵、無效鍵名、未閉合引號及引號後的非法內容直接失敗。
- 不展開 `$VARIABLE`，也不讀取目前程序環境，避免比較結果受執行環境影響。

## 社群短影片

### 內容

七幕、36 秒正體中文直式影片：

1. `.env` 比對不該洩漏秘密。
2. KeySift 只顯示差異，不曝光值。
3. CLI 差異輸出示例。
4. 鍵名級輸出、嚴格解析、穩定排序。
5. Text、JSON 與 glob 忽略規則。
6. CI 退出碼與零 runtime 第三方套件。
7. GitHub 與 MIT CTA。

### 輸出規格

- 1080 × 1920、9:16、square pixels。
- 30 fps CFR，36.067 秒。
- H.264 High Profile、progressive、yuv420p、closed GOP。
- AAC-LC、48 kHz、stereo、128 kbps 目標。
- MP4 Fast Start，無 edit list。
- 正體中文 Microsoft Hanhan 旁白。
- 原創程式合成音床，不使用外部音樂素材。

### 影片驗證

- FFprobe 驗證解析度、比例、幀率、編碼、像素格式與音訊格式。
- Chromium 實際播放成功，影片及音訊解碼位元數持續增加。
- 七幕分鏡與關鍵畫面已人工檢視。
