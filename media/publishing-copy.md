# KeySift 短影片上架文案

## YouTube Shorts

### 標題

```text
你的 .env 比對會洩漏 Token 嗎？KeySift 只顯示差異｜開源 CLI #Shorts
```

### 說明

```text
KeySift 是安全比對 .env 設定漂移的開源 CLI。

它只輸出鍵名與差異狀態，不會把密碼、Token 或其他值寫進 stdout、stderr 或 JSON。支援文字／JSON、glob 忽略規則、嚴格語法檢查，以及適合 CI 的 0／1／2 退出碼。

GitHub：https://github.com/tonnychiulab/keysift
License：MIT

#dotnet #opensource #devtools #security #cicd #Shorts
```

### 建議置頂留言

```text
你最常在哪個環境遇到 .env 漂移：local、staging，還是 production？
專案與安裝方式：https://github.com/tonnychiulab/keysift
```
